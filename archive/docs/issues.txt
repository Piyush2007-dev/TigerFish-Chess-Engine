Worth flagging: since init_rays()/init_magics() run in the constructor and game.cpp constructs a fresh Board on every CLI invocation (moves, make, best all do Board board;), you're recomputing all ~841k magic-bitboard table entries from scratch on every single call. That's wasted work — these tables are static and only need to be built once per process (or even precomputed offline). Worth hoisting into a one-time static init if performance matters.
